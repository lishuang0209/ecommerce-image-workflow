# GitHub 提交身份与贡献记录

本项目提交时使用 GitHub 隐私邮箱：

```text
207018160+lishuang0209@users.noreply.github.com
```

在新的开发环境克隆项目后，可为本仓库配置提交邮箱：

```sh
git config --local user.email "207018160+lishuang0209@users.noreply.github.com"
git config --local --get user.email
```

贡献记录要求提交邮箱关联 GitHub 账号，并进入仓库默认分支。本仓库为私有仓库，需要在个人主页的 Contribution settings 中开启 Private contributions，才能展示私有贡献数量；仓库内容仍保持私有。

符合条件的提交可能需要最多 24 小时才会显示。修改邮箱配置只影响未来提交，不会改变历史提交的作者信息。

参考：[GitHub 缺少贡献排查说明](https://docs.github.com/zh/account-and-profile/how-tos/contribution-settings/troubleshooting-missing-contributions)。
